## 🧠 Sobre mim

Sou Vinicius Barbosa, formado em Análise e Desenvolvimento de Sistemas e desenvolvedor front-end com sólida experiência na criação de interfaces modernas, performáticas e bem estruturadas.
Atuo com React, Vue.js, JavaScript, TypeScript, PHP, Node.js e MySQL, sempre buscando unir qualidade técnica, boas práticas e excelente experiência do usuário.

No React, domino o uso de hooks (useState, useEffect, useContext, useRef), componentização, gerenciamento de estado global, React Router e integração com TypeScript, garantindo escalabilidade e segurança do código. Tenho experiência com o vite-plugin-svgr, otimizando SVGs como componentes React para melhor performance e manutenção.

No Vue.js, trabalho com Composition API, Pinia, Vue Router e comunicação entre componentes via eventos, mantendo o código modular, limpo e de fácil manutenção.

Tenho vivência no consumo e integração de APIs RESTful e WebSockets, desenvolvendo aplicações em tempo real com Axios e Fetch API, aplicando boas práticas de autenticação com JWT, além de validação e tratamento de erros.

No back-end, desenvolvo APIs com Node.js (Express) e PHP, estruturando rotas, endpoints e integrações com MySQL, com foco em desempenho e clareza arquitetural.

Utilizo Tailwind CSS, Material UI e PrimeVue para criar interfaces modernas, responsivas e focadas em UX/UI, seguindo princípios de design responsivo e mobile-first.

Também possuo domínio em Git e GitHub, versionando projetos de forma organizada, com uso de branches, pull requests e commits padronizados, promovendo um fluxo de trabalho limpo e colaborativo.
